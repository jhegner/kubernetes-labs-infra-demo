Exemplo de deployment (simplificado):

```yaml
# frontend-deploy.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: frontend
spec:
  replicas: 1
  selector:
    matchLabels:
      app: frontend
  template:
    metadata:
      labels:
        app: frontend
    spec:
      containers:
        - name: frontend
          image: hashicorp/http-echo:0.2.3
          args: ["-text=frontend"]
          ports:
            - containerPort: 5678
          resources:
            requests: # Minimum resources needed by the container
              cpu: "100m"
              memory: "128Mi"
            limits: # Maximum resources the container can use
              cpu: "200m"
              memory: "256Mi"
```

### 🔄 APIs de Descoberta (xDS)

O Istio usa quatro APIs principais para configurar os proxies:

#### CDS (Cluster Discovery)

- **Função**: Descoberta de Serviços
- **Descrição**:
  - Mapeia serviços disponíveis
  - Define destinos de tráfego

#### LDS (Listener Discovery)

- **Função**: Configuração de Portas
- **Descrição**:
  - Define portas de escuta
  - Configura protocolos aceitos

#### EDS (Endpoint Discovery)

- **Função**: Localização de Pods
- **Descrição**:
  - Fornece IPs e portas dos pods
  - Mantém lista de endpoints ativos

#### RDS (Route Discovery)

- **Função**: Regras de Roteamento
- **Descrição**:
  - Define regras HTTP
  - Configura roteamento de requisições

**Observação**: Gateways usam apenas CDS, LDS e EDS pois operam na borda da malha.

#### 1 Port-Forward direto para o Pod

```bash
# Obter o nome do pod
kubectl get pods -n labs -l app=frontend

# Criar port-forward para o pod
kubectl port-forward -n labs pod/frontend-<pod-id> 8080:5678
```

> Em outro terminal, teste com:

```bash
curl http://localhost:8080
# Deve retornar: "frontend"
```

#### 2 Service Temporário

```yaml
# frontend-service.yaml
apiVersion: v1
kind: Service
metadata:
  name: frontend
spec:
  selector:
    app: frontend
  ports:
    - protocol: TCP
      port: 80
      targetPort: 5678
```

```bash
# Obter o nome do svc
kubectl get svc -n labs

# Criar port-forward para o svc
kubectl port-forward -n labs svc/frontend 80:80
```
