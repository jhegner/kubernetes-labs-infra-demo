# 🚀 Épico A — Fundamentos e Instalação (pré-requisitos)

## 📋 US-001 — Instalar Istio no cluster

### 👤 História do Usuário

**Como** engenheiro que vai aprender Istio  
**Quero** instalar Istio com o profile demo (ou minimal/default)  
**Para que** eu tenha os CRDs, control plane (istiod) e gateways instalados

### ✅ Critérios de Aceitação

- Namespace `istio-system` existe e pods `istiod`, `istio-ingressgateway` (ou `istio-ingress`) estão `Running`
- `istioctl verify-install` passa sem erros críticos

### 📝 Tarefas

- [x] ~~1. Baixar e instalar Istio CLI (istioctl) localmente~~

- [x] ~~2. Instalar Istio com os seguintes comandos:~~

```bash
istioctl install --set profile=demo -y
kubectl label namespace default istio-injection=enabled --overwrite
```

- [x] ~~3. Verificar a instalação:~~

```bash
kubectl get pods -n istio-system
istioctl version
```

### 🔍 Validação

- Verificar se o serviço `istio-ingressgateway` está disponível:

```bash
kubectl get svc -n istio-system
```

- Executar `istioctl proxy-status` depois de implantar um app com sidecar injetado

### 📊 Dificuldade

**Nível**: ⭐ Fácil
